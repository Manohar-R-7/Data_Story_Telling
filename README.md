# Data Storytelling App - IPL Dataset

## Project Overview

This project presents a data storytelling analysis of the Indian Premier League (IPL) dataset from 2008 to 2022. The goal is to uncover meaningful patterns, trends, and insights through exploratory data analysis and visualizations.

## Dataset

IPL Matches Dataset (2008–2022)

## Objectives

* Understand IPL tournament trends
* Analyze team performance
* Examine toss outcomes
* Explore venue usage
* Present findings through storytelling

## Exploratory Data Analysis (EDA)

The dataset was analyzed to identify:

* Total matches played
* Total seasons
* Number of participating teams
* Winning patterns
* Venue distribution

## Visualizations

1. Matches Per Season
2. Team Wins Analysis
3. Toss Winners Distribution
4. Top IPL Venues

## Insights and Findings

* IPL has grown significantly over the years.
* Certain teams have consistently performed well.
* Toss wins do not always lead to match victories.
* A small number of venues host most IPL matches.
* Historical data helps identify long-term trends.

## Conclusion

The analysis highlights the growth and competitiveness of the IPL. Data-driven insights can help understand team performance, venue importance, and tournament evolution.

## Technologies Used

* Python
* Pandas
* Plotly
* Google Colab

## How to Run

1. Open the notebook in Google Colab.
2. Upload the IPL dataset.
3. Run all cells sequentially.
